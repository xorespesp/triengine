# triengine
A simple OpenGL-based 3D data visualization library. <br/>
It uses `Eigen` for its internal math operations, making it convenient for projects that already use it.

### Library Features
- Point cloud rendering
- Line set rendering
- Triangle mesh rendering
- Lighting system
- Order-Independent Transparency
- SMAA
